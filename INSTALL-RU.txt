TMNT 2003 LAN v0.14 — один файл для установки

Нужно: два ПК с Windows, .NET Framework 4.8, одна локальная сеть и одинаковые
копии Teenage Mutant Ninja Turtles (2003). Игра в комплект не входит.

Установка на ОБОИХ ПК
1. Распакуйте TMNTLanLauncher.exe из ZIP в любую обычную папку.
   Для автоматического определения игры положите его рядом с TMNT.EXE.
2. Запустите TMNTLanLauncher.exe. Если путь не выбран — нажмите «Обзор»
   и выберите TMNT.EXE в основной папке игры.
3. Раскройте «Настройки игры»: выберите разрешение, «Без рамок» / «Окно» /
   «Полноэкранный» и VSync ДО запуска. Настройки на двух ПК могут отличаться.
   По умолчанию — разрешение рабочего стола, без рамок, VSync включён.
4. ПК1: «Создать игру». ПК2: «Подключиться», IPv4 первого ПК и запуск.

Для установки нужен ТОЛЬКО TMNTLanLauncher.exe.
PS1, CMD, DLL, JSON и .config рядом с ним не нужны. PowerShell при запуске
игры не используется. Сетевые компоненты встроены в EXE и автоматически
распаковываются в %LOCALAPPDATA%\TMNTCoopLauncher\runtime.
Настройки запоминаются отдельно для каждой папки игры.
Кнопки RU / EN вверху справа переключают язык лаунчера сразу.
Выбор сохраняется на этом ПК без запуска игры. Язык самой игры не меняется.

Если была старая версия LAN-мода
Закройте игру и прежний лаунчер. Используйте новый EXE на обоих ПК.
Совместимый CoopLab можно оставить: его прогресс и настройки сохранятся.
Папка CoopPrototype старой версии для нового лаунчера больше не нужна.
Сначала проверьте новый запуск и сохраните нужные данные перед её удалением.
Старые CMD и ярлыки замените запуском нового EXE.

Графика и меню
В LAN-сессии вход в настройки из главного меню заблокирован: изменение
разрешения внутри игры вызывало сбой Direct3D. Завершите сессию и измените
параметры в «Настройках игры» лаунчера. Настраивайте клавиши/геймпад до LAN.
Если savesetting.dat отсутствует, один раз сохраните настройки обычной игры.
Первый предыдущий файл настроек сохраняется в CoopLab как
savesetting.dat.before-lan-video.bak. Исходные настройки игры не меняются.
Общие меню ведёт хост. Кнопку, зажатую во время ожидания второго меню,
нужно отпустить и нажать снова. Персонажей выбирают оба игрока.

Как играть
Хозяин выбирает сюжетный режим и ДВУХ игроков. ПК1 выбирает первого
персонажа, ПК2 — второго. Каждый использует управление локального «Игрока 1»
на своём компьютере. Геймпад должен быть назначен P1 в настройках игры.
Для клавиатуры щёлкните по своему окну игры. Камера остаётся штатной.
Лаунчер можно свернуть; его закрытие или «Завершить игру» заканчивает сессию.

Игра и сохранения
Лаунчер создаёт CoopLab внутри выбранной папки игры. Там работает LAN-копия
и хранится её savegame.dat. Основной TMNT.EXE не меняется. Имеющиеся
сохранения CoopLab не перезаписываются. При первом запуске можно начать
с чистой игры без savegame.dat; если исходное сохранение есть, используйте
одинаковое сохранение на обоих ПК.
Поддерживаются исходный EXE BC49A82C… и прежняя подготовленная версия F350C7EF….

Если не подключается
Проверьте IP, одну локальную сеть и одинаковую версию мода на обоих ПК.
При запросе Windows разрешите игру в частной сети. Хозяину нужен входящий
TCP 27803. Интернет-сервер и SSH для игры не нужны.
Кнопка «Логи» открывает журнал; для диагностики нужны логи обоих ПК.
Логи, настройки и служебные файлы: %LOCALAPPDATA%\TMNTCoopLauncher.
Редкое зависание загрузки ограничено 20 секундами, затем можно повторить
запуск. Внутренняя причина этого зависания ещё исследуется.

Удаление
Закройте сессию, сохраните нужный savegame.dat из CoopLab, затем удалите
TMNTLanLauncher.exe и CoopLab. Личные настройки, логи и кеш можно отдельно
удалить из %LOCALAPPDATA%\TMNTCoopLauncher. Исходная игра сохранится.

Сборка экспериментальная. Полное прохождение всех уровней пока не проверено.
